分组与流程

4一条主线
1
三分组固定：暂存的更改 / 更改 / 未跟踪。冲突不做独立视图，按文件进入「更改」并标 C。
2
提交框固定 96：消息两行 +「提交」主按钮 + 拆分箭头（提交并推送）+「提交并推送」勾选。
3
行级操作只在 diff 里：每个 hunk 给「暂存此块 / 丢弃此块」，列表里只给整文件的暂存与丢弃。
4
不做：PR、行内评审、子模块、签名提交、rebase 交互面板；同步只保留下拉与推送。

危险操作

二次确认
丢弃更改 · 先列出将丢弃的文件与 +/− 行数，确认后不可撤销
撤销提交 · 保留改动到工作区；文案写明「提交会从历史移除」
强制推送 · 默认不提供；仅在「落后 + 分叉」时给出，并要求输入分支名

提交消息

≤ 72 字
抽成 PreviewCard 组件，复用悬停浮层
动词开头 · 一行说明「做了什么」，细节放正文。
